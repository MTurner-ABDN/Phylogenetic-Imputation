# Phylogenetic-Imputation
Code and data for the imputing species trait data using Tabular prior fitted networks, and making comparisons to RPhylopars and multiple imputation by chained equations using random forest. The files "Script0_RunScripts_V1.0.R", "Script1_SimulateData_V1.0.R", "Script4_CalculateEigenvectors.1.R" and "Process_pem.R" were taken from Johnson et al., (2021) and tweaked for our use.
